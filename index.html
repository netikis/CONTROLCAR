Instalar app
Instalar aplicativo Atalho na Área de Trabalho ou tela do celular
Como instalar COM A LOGO na Área de Trabalho:
1. Apague o atalho antigo (ícone cinza/genérico) da Área de Trabalho.
2. Chrome: menu ⋮ → Instalar Paraná Peças… (ou Salvar e compartilhar → Instalar página como app).
3. Não use “Criar atalho…” — esse atalho fica sem a logo.
4. Edge: menu ⋯ → Aplicativos → Instalar este site como um aplicativo.

iPhone: toque em Compartilhar → Adicionar à Tela de Início para instalar o app com o ícone da Paraná Peças.
